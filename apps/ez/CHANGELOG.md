# Changelog

## 0.2.2 — 2026-11-06

- Keep the native sidebar toggle symbol-only in both display modes by applying
  everyday label styles inside the navigation columns.

## 0.2.1 — 2026-11-06

- Shared symbol sheet and generated native/web mappings. Copy and Send use familiar
  symbols; Min Mode controls match across the main window and Quick Lookup.
- Consistent Connections, Action, Reuse and Min Mode wording across both apps.

## Earlier development

- Typed Write/Draw actions in the shared composer, Quick Lookup and History.
  Connections have stable keys; presets bind connection/capability/model/options.
  Illustration saves PNGs with save-only recovery, Download and frozen inspection.
  Separate API Keychain credentials and billing; no automatic provider fallback.

- Full-row disclosure hit targets across reading views and Settings, with keyboard
  activation and accessible expansion state.

- Readable prose spell checks with paragraph-aligned Original / Corrected columns,
  highlighted edits, expandable explanations, and a compact reading layout.
  Comparison parsing accepts standalone and same-line section labels.

- Look Up in EZ macOS Service fills a draft from selected text without sending or
  changing the clipboard; existing drafts and active work are protected.

- Reading-focused answers with an optional draft composer, quieter request details,
  stable input hints, visible keyboard focus in long forms, and empty-search recovery.
- Configuration edits survive Settings section changes and require an explicit
  choice before unsaved edits are discarded; repeatable native UI QA journeys.

- Persistent local code-signing identity and `make install` upgrades with signature
  validation, running-app checks, and a retained previous bundle for rollback.
- Scroll selectors directly, shared lookup/action keyboard commands, and a Shortcuts
  settings tab with recording, conflict checks, saved overrides, and Chrome navigation.
- Bottom lookup status line with saved token usage, first-text latency, and average
  response throughput after TTFT; unknown metrics remain unavailable.
- Yellow waiting/green reasoning activity light without generation spinners, with
  a stationary Reduce Motion alternative; the light stops permanently once
  answer/refusal text arrives.
- Native macOS dictionary, spelling check, and quick-answer interface.
- Direct Sign in with ChatGPT, protected account profiles, and streamed Responses.
- Account model/effort discovery and capability-dependent Fast requests.
- Local JSONL history, search, Markdown export, and cancellation recovery.
- Swift package, offline contract checks, formatting, macOS CI, and contributor guidance.
- Checksum-pinned SwiftLint/ShellCheck/actionlint, installed commit/push gates,
  warnings-as-errors and complete concurrency checking, and native-script typechecking.
- Dedicated lookup/settings views, immediate preference saving, accessible action
  labels, and correctly dismissible storage warnings.
- In-app Keychain explanation and detailed credential/signing documentation.
- Staged bundle packaging that preserves the previous app on signing failure.
- Compact Quick Lookup panel, global shortcut, menu-bar access, and Raycast query entry.
- Editable actions with generated inputs, named model presets, temporary overrides,
  and original request snapshots retained in history.
- Canonical surface responsibilities and shared, offline native preview tooling.
- Nonblocking credential restoration keeps the window responsive during Keychain access.
