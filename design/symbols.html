Shared control symbols

EZ and Saul share meanings and accessible names. Native controls use SF Symbols; web controls use Lucide. Copy, Send, Refresh and sidebar toggles show symbols in both modes. Other familiar controls may show symbols in Min Mode. Menus and consequential actions keep clear text when needed.

Every symbol button needs a full accessible name and tooltip. Refresh never regenerates; Reuse never sends; closing never stops work. The sidebar symbol is a toggle; opening the main window uses a window symbol.

Web Action Meaning Native / web name

Copied The clipboard write succeeded. checkmarkCheck
Send Submit the current follow-up or message. paperplaneSend
Refresh Read current tabs, accounts or models; never generate. arrow.triangle.2.circlepathRefreshCw
Reload Reload saved settings, confirming discard of a dirty draft. arrow.clockwiseRotateCw
Hide sidebar Hide navigation while retaining the current content and draft. sidebar.leftPanelLeftClose
Show sidebar Reveal navigation without changing the current content or draft. sidebar.leftPanelLeftOpen
Open main window Open the full workspace from a compact surface. macwindowAppWindow
Run Execute the selected action with the current inputs. play.fillPlay
Stop Stop active work; retained output remains available. stop.fillSquare
Reuse Restore a saved request as an editable draft without sending. arrow.uturn.backwardUndo2
Regenerate Start a new generation from the saved request; allowance or charges apply. sparklesSparkles
More Reveal additional actions for the current item. ellipsisEllipsis
Details Inspect saved inputs, output and recorded choices. info.circleInfo
Close Dismiss this surface without stopping active work. xmarkX
Download Save the generated image in its original format. arrow.down.to.lineDownload

Native sidebar visibility uses the system toolbar toggle. Run (EZ), Explain (Saul selection) and Send (message/follow-up) retain distinct names. A symbol does not change execution, permission or billing.
